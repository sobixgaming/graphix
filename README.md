# Sobix Graphix

Modulare Sammlung animierter Grafiken für OBS Studio.

## Struktur

- `index.html` – öffentliche Übersicht
- `overlays.json` – Katalog aller Grafiken
- `overlays/<slug>/index.html` – eigenständige OBS-Browserquelle
- Bilddateien – optimierte Assets mit Transparenz
- `.github/workflows/pages.yml` – automatische Veröffentlichung

## Aktuelles Overlay

- Splitruns Season 2: `https://sobixgaming.github.io/graphix/overlays/splitruns-s2/`
- OBS-Größe: 1664 × 935

Neue Grafiken erhalten immer einen neuen Ordner und eine neue Katalogzeile. Bestehende URLs bleiben dadurch stabil.
